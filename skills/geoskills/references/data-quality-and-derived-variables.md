# 数据质控、组成基准与派生比值

这些功能在绘图前运行，不修改原始文件，也不会自动填补缺失值、替换检出限或修正异常数据。

## 无水100%组成基准

v0.6 可以在私有工作副本中执行显式归一化：

```yaml
data_basis:
  operation: normalize-to-100
  basis: anhydrous-100
  analytes: [SiO2, TiO2, Al2O3, Fe2O3T, MnO, MgO, CaO, Na2O, K2O, P2O5]

confirmations:
  data_basis_reviewed: true
```

每个有效组分按 `组分值 / 所选氧化物总和 × 100` 计算。`analytes` 就是归一化分母的完整定义，必须由用户或专业人员核对。H2O、H2O+、H2O-、CO2、LOI 和 Total 不能进入该列表。总铁列不能与另一总铁列、FeO 或 Fe2O3 重复计入；如果同时报告独立 FeO 和 Fe2O3，可在没有总铁列时共同使用。

`normalize-to-100` 执行实际换算；`use-as-declared` 表示源数据已经是声明的无水100%基准，只作数值有效性检查而不重新缩放。缺失、检出限、非数字、非有限、负值或所选总量不为正的记录不会被修补，其转换结果保持缺失。可分享计划和报告只保存计数与氧化物名称，不保存逐样品总量或转换值。

## 质控检查什么

- 样品编号是否为空或重复；
- 映射分析物中有多少缺失、低于检出限、非数字、无穷、零或负数；
- 如果配方明确要求，可计算指定主量氧化物之和，并统计落在用户给定范围内、低于范围、高于范围或无法求和的记录数。

可分享计划和报告只保存计数，不保存样品编号、问题所在行、单个测值或精确数据范围。需要定位原始问题时，只在本地打开源表核对。

## 配方示例

```yaml
quality:
  duplicate_sample_ids: error
  non_numeric_values: error
  major_oxide_total:
    analytes: [SiO2, TiO2, Al2O3, Fe2O3T, MnO, MgO, CaO, Na2O, K2O, P2O5]
    lower: 95
    upper: 105
    composition_basis: as-reported
    severity: review
```

这里的 `95–105` 只是字段格式示例，不是 GeoSkills 推荐的通用阈值。实际范围、所含氧化物和 `composition_basis` 必须依据实验室 QA/QC、文章方法和专业复核填写。如果不需要主量总量检查，应写 `major_oxide_total: null` 或省略整个 `quality` 段。

策略含义：

- `warning`：记录问题，但不阻止生成计划；
- `review`：需要在 `confirmations` 中明确设置 `data_quality_reviewed: true` 才能运行；
- `error`：阻止运行，应先修正数据或配方；
空白或重复样品编号始终是错误，不能通过确认项绕过。如果两行代表平行样或重复分析，应为每条分析记录设置唯一编号，再用分组列或单独的本地元数据记录其关系。

## 派生比值

公开配方只允许固定除法，并要求分子和分母的已声明单位完全相同：

```yaml
derived_variables:
  - id: Nb_Y
    operation: ratio
    numerator: Nb
    denominator: Y
    input_unit: ppm
```

计算规则：

- 只计算分子和分母都为正有限数的记录；
- 缺失、检出限、非数字、无穷、零或负值对应的结果保持缺失；
- 不执行用户公式、Python/R 代码或 `eval`；
- 不允许 `ppm/wt%` 等混合单位比值，也不进行隐式换算；
- 计划和报告保存公式定义及有效/无效记录计数，不保存逐样品比值。

跨单位比值只能作为经过文献与专业审核的分类模型变量，由分类模型中的显式比例因子处理，不能借普通 `derived_variables` 绕过。

## 质控代码

| 代码 | 含义 |
|---|---|
| `Q001` | 样品编号有空白，阻止运行 |
| `Q002` | 样品编号重复，严重程度由配方决定 |
| `Q003` | 非数字或非有限内容 |
| `Q004` | 缺失项 |
| `Q005` | 低于检出限标记，保持缺失 |
| `Q006` | 零或负数 |
| `Q007` | 完整主量记录的显式求和超出配方范围 |
| `Q008` | 部分记录无法完成主量求和 |
| `D101` | 一个派生比值没有任何有效记录，需要复核 |
| `D102` | 一个派生比值只对部分记录有效 |
| `B101` | 没有任何记录能安全形成无水100%基准，阻止运行 |
| `B102` | 部分记录不能形成无水100%基准，对应转换值保持缺失 |
