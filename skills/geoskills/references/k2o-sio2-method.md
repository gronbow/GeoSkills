# K2O-SiO2 岩浆系列图科学合同

## 用途与输入

该图用于比较已确认火山岩全岩分析的 K2O-SiO2 岩浆系列位置：

```text
x = SiO2 (wt%)
y = K2O (wt%)
```

只接受无 H2O、无 CO2 的100%组成基准。使用配方中的 `data_basis` 时，必须明确列出进入归一化分母的全部主量氧化物，并由人确认；程序不覆盖源列，不填补缺失值，也不把 LOI、H2O、CO2 或 Total 放入分母。

需要明确确认样品属于该火山岩图解的适用范围。强烈蚀变或发生明显钾迁移的样品不能仅凭此图确定岩浆系列。

## 文献边界

使用 Peccerillo and Taylor (1976) 的原始边界，并按 Rickwood (1989) Table 2 的数值核对：

- 拉斑玄武质/钙碱性：`(48,0.3), (52,0.5), (56,0.7), (63,1.0), (70,1.3), (78,1.6)`；
- 钙碱性/高钾钙碱性：`(48,1.2), (52,1.5), (56,1.8), (63,2.4), (70,3.0)`；
- 高钾钙碱性/橄榄安粗岩质：`(48,1.6), (52,2.4), (56,3.2), (63,4.0)`。

所有坐标单位均为 wt%。第二条边界在 `SiO2 = 52` 的 `K2O = 1.5` 是 Rickwood 指出的更正值；不得恢复为原文误印的 `1.3`。

边界不外推。三条线共同覆盖的完整四分区范围只有 `SiO2 = 48–63 wt%`。程序可以显示固定图框内的其他样品，但必须返回 `outside`，不得根据较短边界的趋势强行分类。恰好落在边界上的点返回 `review_boundary`。

## 图件与解释

- 使用完整四边框、线性坐标、颜色加符号的分组编码和碰撞检查图例；
- 图中用淡色背景表示完整四分区范围，用虚线标出其左右界；
- 图下注明无水100%基准、两篇文献、未外推以及完整分类范围；
- 报告分类计数、字段计数、边界复核数和范围外数，不在可分享报告中保存样品编号或源值；
- 只描述样品落入或接近哪个系列区域。不要从该图单独推断岩浆源区、分异过程或构造环境。
