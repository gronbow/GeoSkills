# 通用分类模型合同

这是 v0.5 为后续分类图准备的开发底座，不代表 GeoSkills 已支持新的分类图。正式加入任何图解前，边界、变量公式、适用岩石类型和标签仍需地球化学专业复核，并需要单独的图解注册、示例、视觉审核和发布批准。

## 一个模型必须说明什么

分类模型是本地 UTF-8 JSON 文件，必须包含：

- 固定的 `schema_version`、模型 ID 和版本；
- 原始文献引文、可选 DOI，以及边界取自文献中的图、表或公式的位置；
- `scientific_review.status`，公开运行默认只接受 `approved`；
- X/Y 变量的结构化定义、输入单位、比例因子、输出单位和与结构一致的显示公式；
- 线性或对数坐标、固定范围、分区多边形和可选标签位置；
- 固定的边界、重叠和图外处理策略。

读取模型时可以绑定 SHA-256。文件变化后，旧哈希不再有效，不能静默沿用旧审核结论。

## 变量计算

底座只实现两种结构化操作：

- `direct`：一个已映射分析物乘以明确比例因子；
- `ratio`：两个已映射分析物相除，再乘以明确比例因子。

显示用 `formula` 必须与结构化字段严格一致。程序不会解析或执行公式文本，因此 JSON 不能成为任意代码入口。普通同单位比值应优先使用配方的 `derived_variables`；分类模型中的比例因子主要用于文献明确规定的尺度和单位转换。

## 几何和分类规则

- 对数轴的范围、边界顶点和标签位置必须为正；
- 每个多边形至少三个互不重复的顶点，面积不能为零，也不能自相交；
- 线性轴和对数轴先转换到统一的 0–1 轴空间，再计算边界容差，避免单位尺度改变边界判断；
- 点恰好落在边界上时返回 `review_boundary`，不静默分到任一侧；
- 点同时落入多个分区时返回 `review_overlap`；
- 点不在任何分区时返回 `outside`；
- 坐标无效时返回 `invalid`。

## 专业复核清单

为某篇文献建立真实模型资产前，至少核对：

1. 图解适用的岩石类型、蚀变条件和数据前处理；
2. 文献使用的是元素、氧化物、质量分数还是经过缩放的比值；
3. 坐标轴是线性还是对数，以及比值缩放顺序；
4. 每条边界的原始数字来源，不能仅凭低分辨率图片目测；
5. 分区名称、缩写、边界共有关系和图外区域；
6. 文献中的边界归属规则；没有明确规则时保持 `review`；
7. 用已知控制点和文献示例做独立复算与视觉对照。

GEOROC 等公开数据库可以用于覆盖范围、异常输入和回归测试，但不能替代文献边界复核，也不应被用来“训练”程序重新发明分类线。数据许可、引用、筛选条件和版本日期必须单独记录。
