# 第一次使用与常见问题

GeoSkills 在你的电脑上读取数据和绘图。安装后先让助手运行环境检查，再提供本地文件和想画的图。

## 我需要准备什么？

准备 CSV、TXT 或 XLSX 文件，明确样品编号列、分组列和元素单位。ppm 与 wt% 不能混用。Excel 有多张工作表时，请指出需要哪一张；不必为了出图修改原始文件。

## 为什么先给我计划，没有直接出图？

计划是运行前的核对单。确认列映射、标准化方案和输出尺寸正确后批准运行。`needs_confirmation` 表示还缺人工确认，`blocked` 表示存在需要处理的问题；`review` 可以表示图件已生成，但还需要科学复核。

## 重复表头（E110）

两列叫同一个名字会造成歧义。例如两列都叫 `La_ppm`，程序无法替你判断哪一列应该使用。在数据副本中给它们清楚的名称，再重新选择列映射。错误只报告重复数量，不显示私有列名。

## 输出目录拒绝覆盖（E826）

程序发现旧结果不完整、任务文件或 QA 摘要被修改，或目录中加入了其他文件。把新结果输出到另一个目录，例如 `results-run-2`；原目录保留供你比较。不要为绕过检查删除笔记。手工注释建议始终存放在结果目录之外。

## 旧计划不能继续用

改了数据、配方、软件版本或参考资产后需要重新生成计划。这可避免你审核的是旧参数，运行的却是新数据。

## 哪些东西可以分享？

默认 `shareable` 不输出逐样品 CSV，但图件仍展示测量关系和分组名称。分享前应检查分组是否透露地点或项目，并确认图件本身可公开。`local-reproducible` 的 CSV 包含真实绘图数据，应按研究数据权限保管。

## 如何检查投稿图件？

按实际单栏或双栏尺寸打开 PNG，检查文字是否清晰、图例是否遮挡数据、分组是否能在灰度下区分，再检查 SVG/PDF 可编辑版本。单栏模式有元素/面板数量限制；超限时选择双栏或拆分任务。期刊的具体尺寸要求仍以投稿指南为准。
