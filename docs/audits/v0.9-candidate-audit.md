# GeoSkills v0.9 本地候选审查

审查日期：2026-09-08。基线：已发布 v0.8.0，提交 `266df3f`。本轮为 `0.9.0-rc1`；用户已批准候选版提交与上传，合并及正式发布仍待审核。

## 产品现状与范围

当前产品是本地 Python Skill 和命令行工具，不是独立 Web 应用。本轮审阅了项目入口、安装说明、Skill 指令、表格读取、配方限制、输出事务及报告清单、CI 和远程仓库安全设置，并以完整测试集检查科学与工作流回归。未开展第三方渗透测试，也未重新复核文献数值；未改变科学资产或图形算法。

## 发现与完成的修改

| 优先级 | 原问题与影响 | 候选版处理 |
|---|---|---|
| 高 | 有效旧报告足以允许整体覆盖，后来加入的笔记也可能丢失 | 核对输出清单、文件大小、SHA-256 和根目录 QA；发现额外文件、空目录、缺失或修改即停止 |
| 高 | pandas 会把重复表头自动变为 `.1` 等名称，掩盖数据列歧义 | 在表头解析前检查重复，CSV/TXT/XLSX 均返回 E110；错误仅包含数量 |
| 中 | 文本嗅探先读取整个文件再截取前 64 KiB | 改为有界读取，减少大文件内存开销 |
| 中 | 首页宣称 v0.6 为正式版、v0.8 未发布 | 纠正正式下载链接，明确当前开发版本，清除 Skill 与流程页的过时候选标题 |
| 中 | 新手需要穿过很长的开发说明 | 增加入口导航、可下载正式版链接和中文排错页，折叠旧命令 |
| 中 | 分支 push 和 PR 各运行相同测试矩阵 | push 限于 main，保留 PR 和手动触发，取消同一 PR 的过时检查 |
| 中 | 用户曾采用的 localdata 拼写与本地环境变量文件未忽略 | 加入忽略规则，保留 `.env.example` 文档模板 |

默认仍保留配方人工确认、过期计划失效、源数据本地处理、整套输出提交、现有六类图件及科学范围限制。按 skill-creator 的要求，新增约束放在实际相关的位置，避免把开发审查流程塞进普通绘图流程。

- 重复表头：三种输入格式分别测试自动布局与显式行布局，共六个回归用例；私有列名不进入错误。
- 覆盖保护：新增文件、额外空目录、同字节数图件修改、文件删除、根 QA 修改均阻止绘图，原目录逐文件字节保持一致。
- 原有单任务和多任务中途失败测试仍保留，并验证旧图件不变。
- 依赖声明经 `pip-audit --strict --requirement requirements-dev.txt` 查询，重试后返回 `No known vulnerabilities found`。首次 TLS 查询失败，不能当作通过；最终有缓存写入警告但退出码为 0。
- Skill 结构验证通过。Windows 验证器需用 UTF-8 模式读取现有中文内容。
- Git 差异空白检查通过；新隐私忽略规则已验证；科学资产无差异。
- 完整回归为 **294 passed, 1 skipped**（95.25 秒）；随后新增正常完整目录可覆盖、有界文本嗅探两项验收，**2 passed**（2.03 秒）。最终代码未在这两项测试之后修改。云端 CI 须待用户批准上传后运行。

## 剩余限制与后续路线

1. **发布与安装可靠性，建议下一轮优先。** 当前依赖使用版本范围，本次漏洞查询只覆盖解析出的版本，不能证明所有允许的旧版本都安全。设计最低版本与当前版本的两组测试，再制作分平台锁定清单和软件物料清单；不要机械合并五个升级下限的 Dependabot PR。增加正式发布前文档版本一致性检查，避免再次出现发布成功而首页过期。
2. **用户引导与图形验收。** 先做本地配方向导，帮助选择工作表、列映射、单位与尺寸，所有科学确认仍由用户作出；用合成数据扩充长分组名、缺失数据、密集数据的图形验收。之后再评估独立 Web 界面的价值及本地文件生命周期。本轮仅优化 Markdown 项目入口，未进行 GitHub 实际渲染截图验收。
3. **代码维护与性能。** 在读取次数和峰值内存有测量基线后，逐步统一注册表及减少多任务重复解析。保留确定性与资源上限，不引入跨任务不受控缓存。
4. **专业图件扩展。** 同位素年龄校正、演化线和新的构造判别边界需要独立科学规格。GEOROC 可作为有来源记录的回归样本，不用于学习或改写文献边界。

远程设置只读核验：`main` 未受分支保护，Dependabot 自动安全更新关闭；密钥扫描和推送保护已开启。建议审核后启用主分支必需检查与安全更新。这些是 GitHub 管理设置，本轮未更改。

覆盖清单是意外修改保护，不是防篡改签名。报告自身无法对自身做可信签名；若有人同时修改报告及清单，本机制不提供真实性保证。请勿在运行过程中并发编辑输出目录。旧版或人工改写的 QA 无法通过核验时，使用新目录即可保留原结果。
